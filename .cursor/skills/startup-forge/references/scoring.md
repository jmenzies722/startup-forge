# Scoring

Score each axis 0–10. Total /100.

## Axes

| Axis | What "10" looks like |
|---|---|
| Cool | Instant demo lust; design/interaction can be a brand |
| Pain | Specific person pays money or time weekly to escape this |
| Market timing | Why-now is real in 2026 (platform shift, cost curve, regulation, habit change) |
| Crowding / edge | Named wedge vs incumbents; not "we'll AI better" |
| Solo ship | One founder + AI crew can ship MVP in ≤4 weeks |
| Revenue clarity | Who pays, price, first channel, path to $1k MRR or first $1k sales |
| YC fit | Matches a live RFS or classic YC pattern (habit, wedge, expansion) |
| Distribution | Plausible free/cheap acquisition loop |
| Retention / habit | Reason to return without ads nagging |
| Shua Labs fit | Agents, platform, interactive craft, agency thesis |

## Verdict math

- **GO** if total ≥ 72 and no axis ≤ 3
- **PIVOT** if 55–71, or one ≤3 with a clear rewrite that can re-score ≥72
- **KILL** if <55, or two+ axes ≤3, or banned.md match with no rewrite

## Confidence

- **high** — live sources cited for competitors + demand + pricing
- **medium** — partial live research
- **low** — tools unavailable or thin evidence

## Honesty rules

- Cap **YC fit** at 6 if the idea is a micro-product (still valuable)
- Cap **Cool** at 5 if it is useful but boring
- Cap **Crowding / edge** at 4 if top 5 competitors already own the loop
- Never average your way out of a fatal distribution or solo-ship problem
