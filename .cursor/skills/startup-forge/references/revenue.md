# Revenue

Every GO needs a first-dollar path.

## Prefer clear models

| Model | When |
|---|---|
| Subscription $8–$20/mo | Daily/weekly habit consumer or prosumer |
| Seat $15–$49/mo | Team workflow |
| One-time $9–$79 | Micro: template, CLI, kit, small tool |
| Usage | Only if unit economics obvious |

## 30-day first dollar plan

Must include:

1. Offer (what they buy)
2. Channel (where first 20 buyers come from)
3. Asset (landing page, PH, Twitter demo, waitlist)
4. Number target (e.g. 10 paying or 100 waitlist emails)

## Red flags

- "We'll monetize later" with no proxy metric
- Ads-only on day one with no organic loop
- Enterprise sales as the only path for a solo founder

## Micro mode bias

Optimize for:

- Ship in 7–14 days
- Public demo
- Indie Hackers / X / Reddit / Gumroad / Polar / Lemon Squeezy
- Reinvest cash into the bigger venture
