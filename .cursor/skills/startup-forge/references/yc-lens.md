# YC lens

Use when mode is `yc` or when scoring YC fit.

## Live check

Always fetch or search current YC Requests for Startups (`https://www.ycombinator.com/rfs`) when tools work. Map the idea to **at most two** RFS themes. If none fit, say so — still can be a good company.

## What YC usually wants (practical)

- Clear user + painful job
- Small wedge → large market
- Fast product iteration
- Founders who build
- Something that can become a default habit or default infrastructure

## Write `YC.md` with

1. One-sentence company
2. Problem
3. Solution (demo)
4. Why now
5. Wedge + expansion
6. Competition (honest)
7. Traction plan for next 8 weeks (even if pre-launch: waitlist, dogfood metrics)
8. Ask (what batch would unlock)

## Do not

- Force-fit every micro-product into a unicorn story
- Claim "no competitors"
- Lead with TAM theater
